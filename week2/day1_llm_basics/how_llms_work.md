# How LLMs Work

## Core Definition
LLMs are next-token prediction systems trained on massive text data.

## Key Pipeline
1. Data collection
2. Tokenization
3. Embeddings
4. Transformer processing
5. Attention mechanism
6. Next-token prediction

## Important Realization
LLMs do not think like humans.
They statistically generate likely continuations.

## Training vs Inference
Training = learning patterns
Inference = using learned patterns

## Hallucination
LLMs optimize for plausibility, not truth.
