# Tokens and Tokenization

## What is a Token?
A token is a chunk of text processed by an LLM.

## Important Realization
LLMs do not directly understand words.
They process token IDs and vectors.

## Tokenization Pipeline
Text → Tokens → IDs → Embeddings → Transformer

## Subword Tokenization
Words can be split into smaller pieces.

Example:
unbelievable → ["un", "believ", "able"]

## Why Tokens Matter
- API pricing
- Context limits
- Prompt optimization
- Performance

## Why LLMs Struggle With Math
LLMs predict patterns probabilistically.
Math requires exact symbolic computation.
